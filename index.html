Set up editing mode
Step 1 of 4 — Create a GitHub access token

This lets the site save your edits directly to GitHub. You only do this once.

  1. Open github.com/settings/personal-access-tokens/new
  2. Sign in to GitHub if asked.
  3. Fill out the form like this:
    • Token name: Ecref editor (or anything you'll recognize)
    • Expiration: 90 days (longer is more convenient, shorter is safer)
    • Description: (optional)
    • Resource owner: your username
    • Repository access: Only select repositories → pick your Ecref repo
    • Repository permissions → expand → find Contents → set to Read and write
  4. Click the green Generate token button at the bottom.
  5. Copy the token (starts with github_pat_) — you'll paste it in the next step.
Step 2 of 4 — Paste the token

Tokens look like github_pat_AAA_BBB...

Stored encrypted in your browser. Never sent anywhere except GitHub.
Step 3 of 4 — Choose a password

This password protects your access token (so even if someone gets hold of your laptop, they can't use the token without it).

Use the same password as your Clinical Reasoning / Patients gate for simplicity.
