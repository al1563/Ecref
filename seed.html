Vercel KV admin

Use this page after setting up Vercel KV. It runs same-origin so no CORS issues. Anyone who knows your EDITOR_PASSWORD can use these tools.

1. Check KV status

2. Seed KV from this site's reference_data.json

Replaces whatever's currently in KV with the contents of reference_data.json served by this site.

3. Back up KV (download as JSON)

Saves the current KV contents to a JSON file you can commit to the repo as a snapshot.
