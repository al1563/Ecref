Vercel KV admin

Use this page after setting up Vercel KV. It runs same-origin so no CORS issues. Anyone who knows your EDITOR_PASSWORD can use these tools.

0. Configuration health

Shows which env vars the server can see. All boxes should be true for the corresponding feature to work.

2. Seed KV


Replaces whatever's currently in KV with the chosen source. Two options:





Option A — Seed from this site's reference_data.json



  






Option B — Seed from an uploaded JSON file


Pick a reference_data.json or a previously-downloaded backup. Must be {"database": [...]}.




  









3. Back up KV (download as JSON)


Saves the current KV contents to a JSON file you can commit to the repo as a snapshot.









4. Seed extra KV sections (one-time, after deploy)


Populates the new list sections. Uses the editor password from above.
